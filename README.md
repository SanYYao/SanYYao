> **`冰`**：取自于《道德经》第八章的[**上善若水**](https://www.google.com/search?q=详细讲一下“上善若水”是什么意思？&udm=50)里面的水，冰是水的不同形态，**只不过更锋利**

> **`笙`**：是我想要表达，我需要一个发声的方式，作为媒介把我想发出的声音发出去
